# TypeMaster user guide

## Start a candidate assessment

Open TypeMaster, select a saved candidate or choose **I am a new user**. Use one profile per candidate so test history and assessment remarks remain separate.

## Take a typing test

Open **Typing Test**, select a text or number test and choose the duration. Start the test and type in the entry area. On completion, continue to the results screen. A stopped or unfinished attempt can have a partial status; completing a test and passing its targets are separate outcomes.

Results include gross speed, net speed, accuracy, duration and recorded error information. The examination sheet uses the saved original and typed text. Older imported records without a text snapshot cannot reconstruct a word-by-word examination sheet.

## Record practical skills and remarks

Open **Statistics → Progress Report → Skills & Remarks**. Search the catalogue or use its filters, then select the skills the candidate demonstrated. Excel calculations, functions, PivotTables and related tasks appear under Excel in the report. Word, PowerPoint and other skills appear under their own application headings.

For an unlisted skill, enter its name, choose its application and add it. Enter free-form remarks and the examiner in **Test taken by**. Apply to save, or cancel to discard pending edits. Unticked custom skills can remain in the catalogue for reuse; assessment ticks belong to the candidate.

These are manual examiner observations. Selecting a function does not mean TypeMaster tested that function in Excel.

## Preview and export

Review the progress report and use its PDF or print controls. The report includes compact typing history, selected application skills, remarks and the examiner footer. Other available outputs include individual test results, certificates and examination sheets.

## Change company branding

Open **Settings → Company Branding**. Enter the company name and choose logo images. Review the preview and save. Restore defaults to return to the supplied Nirmal Poly Plast branding. Branding settings apply to reports for the current Windows account.

## Back up profiles

Use **About → Profile Backup & Restore** to open the backup controls. Export a candidate profile to a safe location. Restore a backup through the matching restore control. Restored profiles receive a separate identity; an existing profile is not silently overwritten.

Profiles are stored under `%LOCALAPPDATA%\TypeMasterNative`. Portable mode refers to launching without installation; profiles still use the current Windows account's local storage. Keep candidate backups and generated reports out of public repositories.

## Typing Meter

Typing Meter is optional. When enabled, it records typing-activity statistics through Windows keyboard events. Use its pause, stop or tray controls when it is not needed. Exit its tray icon before updating or uninstalling TypeMaster.
## Updates

Open **About → Updates & GitHub** to check for a newer stable release or change automatic checking. Download and installation require your action. Portable users can download and extract the release ZIP. See [the update guide](UPDATING.md).
