# Updates and GitHub

TypeMaster is a typing-practice application customised for computer assessments and candidate reports. Technical skills and remarks are entered by the examiner.

- Project: https://github.com/yateshr/TypeMaster
- Releases and portable ZIP downloads: https://github.com/yateshr/TypeMaster/releases

## For users

Open **About > Updates & GitHub**. You can turn automatic checks on or off, check immediately, open GitHub, download a newer stable installer and choose when to install it.

Automatic checks run at most once per day. They contact GitHub's public release API with the application version in the user-agent; candidate records are not uploaded. Offline checks do not prevent practice or assessments. Automatic notifications are suppressed during exercises, while another application is active, or while another TypeMaster dialog is open.

Downloads only use a version-matched installer in this project's GitHub release. The downloaded size and SHA-256 digest must match GitHub's asset metadata. Missing verification metadata leaves the release-page link available but does not enable installer execution. The digest checks file integrity; it does not make the installer code-signed.

Installation requires an explicit user action. TypeMaster saves candidate records and creates a pre-update profile snapshot before exiting. Setup waits for the old process and installs into the existing installation directory. Candidate records and company branding remain in the user's local application-data directory.

Portable users should download the new ZIP and extract it completely into a new folder. Choosing the installer from a portable copy creates a normal Windows installation.

## For releases

Publish a stable, non-draft GitHub release with a three-part version tag such as `v1.11.9`, and upload `TypeMaster-Native-1.11.9-Setup.exe`. The version in the tag and installer filename must agree. GitHub supplies the asset's SHA-256 `digest` in its release API metadata.

Also upload the portable ZIP and `SHA256SUMS.txt` generated by the native build. Changing a release title alone does not update an installed application. The updater only offers a version newer than the compiled application version; it never downgrades a local preview to an older public release.

API contract: https://docs.github.com/en/rest/releases/releases#get-the-latest-release
