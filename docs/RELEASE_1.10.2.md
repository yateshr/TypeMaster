# TypeMaster v1.10.2

First GitHub release of **TypeMaster**, a native Windows application for typing practice and interview candidate assessments.

![TypeMaster](https://raw.githubusercontent.com/yateshr/TypeMaster/main/docs/images/banner.svg)

## Highlights

- Timed text and number tests with saved speed, accuracy and error details.
- Lessons, custom key review, statistics, six games and optional Typing Meter.
- Searchable skills checklist with 521 Excel function names, practical skills and custom entries.
- Skills grouped by application, free-form examiner remarks and **Test taken by**.
- Compact progress reports with configurable company name and logos.
- Selectable-text PDF results, certificates, examination sheets and complete progress reports.
- Profile backup/restore and recovery support.
- Native window controls and display-layout refinements.
- Removed legacy license-key controls and license-status labels.

![Candidate progress report](https://raw.githubusercontent.com/yateshr/TypeMaster/main/docs/images/progress-report.png)

## Download

| Asset | Instructions |
|---|---|
| `TypeMaster-Native-1.10.2-Setup.exe` | Run to install for the current Windows account |
| `TypeMaster-Native-1.10.2-win-x64.zip` | Extract completely and run `native-win-x64-1.10.2/TypeMaster.exe` |
| `SHA256SUMS.txt` | Check installer and ZIP integrity |

Windows 10/11 x64. The .NET runtime is bundled. The installer is unsigned. Close TypeMaster and exit the Typing Meter tray icon before upgrading. Portable mode still stores profiles in the current Windows account's local app-data folder.

## Assessment workflow

Create/select a profile → Take the typing test → Open Statistics / Progress Report → Skills & Remarks → Apply → Preview / export PDF.

Office skills are examiner-entered observations; this release does not automatically grade Excel, Word or PowerPoint tasks.

## Verification

341 native application checks passed. Five demonstration PDF reports passed extraction and viewer word-selection hit-area checks. Actual application screenshots and sample PDFs are included in the repository.
