El Satélite de TypingMaster es un asistente personal de aprendizaje que le guía mientras utiliza otros programas. Además, recopila información y le ofrece práctica para aquellas teclas y palabras difíciles.

El Satélite será de mayor utilidad cuando haya completado este curso y empiece a utilizar su nueva técnica de escritura diariamente. Entonces, el Satélite continuará perfeccionando eficazmente su técnica.

También puede activar ya el Satélite para ver cómo funciona. Puede probar las características de práctica, empezar a almacenar estadísticas de palabras escritas y usar la opción de recordar tomar una pausa.

Para utilizar el Satélite:
1. Pulse "De acuerdo"
2. Elija "Satélite" en el menú a la derecha
3. Siga las instrucciones de la pantalla para lanzar el Satélite
