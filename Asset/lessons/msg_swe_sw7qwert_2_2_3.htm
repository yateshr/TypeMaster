Om du själv vill bestämma hur mycket tid du vill använda till övningarna, istället för att låta TypingMaster guida dig, kan du alltid stänga av Optimerad Längd.

För att stänga av Optimerad Längd:
1. Klicka OK för att komma tillbaka till lektionsskärmen
2. Klicka på "Justera kurslängd" knappen
3. Klicka "Stäng av Optimerad Längd"



Med Optimerad Längd kommer du att få bästa möjliga träning som möter dina personliga behov och sparar tid!
