Le Satellite est un assistant d'app- rentissage personnel. Il analyse votre écriture dans autres programmes et vous délivre un entraînement pour les touches et les mots qui vous semblent toujours être difficiles.

Le Satellite est plus efficace une fois que vous avez terminé ce cours et commencé à mettre en pratique quotidiennement vos nouvelles compétences dactylographiques. Dès lors, le Satellite vous aidera efficacement a réctifier votre niveau.

Cependant, vous pouvez déjà activer le Satellite pour essayer les options d'entraînement, commencer à enregistrer des statistiques, et utiliser l'option de rappel pour faire des pauses.

Pour utiliser le Satellite :
1. Cliquer OK
2. Choisir « Satellite » depuis le menu sur la droite
3. Suivre les instructions sur l'écran pour lancer le Satellite
