# Asset attribution and scope

The MIT license in this repository applies to the original TypeMaster application source and original project documentation. It does not relicense third-party material or grant rights to company trademarks.

## Supplied runtime and reference material

The project includes supplied artwork, course/lesson data, test content, localization resources and UI reference images originating from TypingMaster12. The repository owner confirmed permission to redistribute this supplied material for this release. These resources retain their respective ownership and are not covered by the TypeMaster source-code MIT grant.

Relevant locations are `Asset/` (other than original TypeMaster branding and the documented catalogue) and `UI/`. Original third-party executables, DLLs, unused licensing files and editor-state files are excluded from the repository and build. The About reference image has been replaced with a demonstration capture of TypeMaster rather than publishing the original licensing-information screenshot.

TypeMaster is an independent application. No endorsement or affiliation with TypingMaster or Microsoft is claimed.

## Company branding

The default Nirmal Poly Plast Private Limited name and RATAN/KOLORR logos are supplied company branding. Their owners retain all trademark and image rights. Settings allow another organization to configure its own name and logos.

## Excel function catalogue

`Asset/excel-functions.json` records function names, categories and version information from Microsoft's alphabetical function reference, captured on 24 October 2026. The import tool is in `Native/Tools/ImportExcelCatalog.py`.

Reference: https://support.microsoft.com/en-us/excel/excel-functions-alphabetical

Microsoft Excel, Word, PowerPoint and Outlook are trademarks of their respective owner. Listing a function does not imply it is available in every Excel version.
