# Contributing

Read [the build guide](docs/BUILDING.md), reproduce the issue and keep changes focused. Include the problem, resulting behavior and relevant validation in your pull request.

Preserve saved profile compatibility and the distinction between test completion and pass status. Keep skill identifiers stable so existing candidate selections remain valid. Report exports must preserve selectable text, readable pagination and company headers.

For UI changes, provide before/after captures and test relevant window sizes and Windows scaling. For scoring or PDF changes, run the native checks and independent PDF verifier. Use demonstration data in screenshots, reports and tests.

Do not commit candidate profiles, backups, generated builds, credentials or logs. Retain third-party attribution and avoid representing supplied third-party assets as newly authored TypeMaster content.
