# TypeMaster 1.11.13

Run the installed TypeMaster shortcut, or extract the complete portable ZIP and open `native-win-x64-1.11.13/TypeMaster.exe`. Close TypeMaster and its Typing Meter tray icon before updates.

The native C# / WPF solution is `TypeMaster.Native.sln`. See the repository's main README and `docs/BUILDING.md` for build and test instructions.

## Candidate workflow

Select or create a profile, complete a typing test, then open Statistics → Progress Report → Skills & Remarks. Select demonstrated application skills, add remarks and the examiner name, apply, and export or print the report.

Company name and logos can be configured in Settings → Company Branding. Candidate profiles use `%LOCALAPPDATA%\TypeMasterNative`; use profile backup and restore to move data safely.

Reports include results, certificates, examination sheets and complete progress reports. Text remains selectable in PDF exports. Examination corrections need the stored original and typed text snapshots.

Skills are entered by the examiner, not automatically graded in Microsoft Office. Excel-function availability depends on the installed Excel version.
